# Salah Window

Android app for the five daily prayers — **deadline defense**, honest On Time / Late / Missed / Qada logging, offline-first, no ads.

**Package:** `com.salahtracker`  
**This repository** hosts public **release binaries** and a short project description only. Application source is maintained privately.

## Download

Get the latest signed APK from **[Releases](https://github.com/m-d-nabeel/SalahWindow/releases)**.

Install notes:
- Allow install from the browser/file manager when prompted.
- Prefer keeping a local backup folder (in-app) before upgrading across major changes.
- Exact alarms / OEM battery settings may need a one-time allow so deadline alerts fire.

## What it is

- Countdown to the **end** of each prayer window (Ends In)
- Honest hygiene logging (not streak theater)
- Beep-only alarms (no musical Adhan packs)
- Geometric UI only (no animate beings in icons)
